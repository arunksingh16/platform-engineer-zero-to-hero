12 lessons, about 15-25 minutes each

Networking fundamentals

Before choosing a load balancer, understand the packet. Learn to design, secure and debug the paths connecting users, services and data, then map those decisions to AWS, Azure or a fleet of VMs.

Think like a production network engineer

For every hop ask: who resolves the name, who opens the connection, where does TLS end, what changes the address, and what happens when this hop fails?

  1. Build a mental model with a small worked example.
  2. Predict a failure or make a design decision.
  3. Reveal the exercise answer, then pass the quiz.

No cloud account or paid resources required. Basic familiarity with processes and client/server applications helps; Kubernetes is not a prerequisite.

Lessons

    One running example

    A fictional music-streaming platform serves catalog searches, private playlists, media segments and persistent client connections. These are large-scale engineering scenarios, not a description of Spotify's internal architecture. Cloud mappings are limited to AWS and Azure; self-managed examples use Linux VMs.

    Continue into the platform

    After the fundamentals, follow the Pod networking and CNI track, apply them to AKS networking and IP planning, and connect network symptoms to observability and SLOs.
